SLA Clock’s Official Start

Could legitimately be defined as any one of the four points to the left — depending entirely on contract language:

Attacker Action — 01:00
Log Reaches SIEM — 01:21
Alert Generated — 01:24
Analyst Acknowledges — 01:29
If the SLA clock starts at alert generation, the SOC’s 5-minute acknowledgement looks great. If it starts at the attacker’s first action, the same case is already 29 minutes old before anyone touches it.
