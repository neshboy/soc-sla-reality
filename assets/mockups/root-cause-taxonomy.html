SLA Breach Root-Cause Taxonomy
Seven branches cover the breaches in this report. Naming the branch is the first line of any credible breach review — not the analyst's name.
SLA BREACH
Branch 01
Capacity
Three P1s, two analysts on shift.
Branch 02
Detection noise
False positives eating triage time.
Branch 03
Tool failure / telemetry delay
SIEM ingestion lag.
Branch 04
Customer dependency
Non-responsive account owner.
Branch 05
Third-party / vendor dependency
Cloud provider, ISP, MDR.
Branch 06
Definitional
Severity reclassified mid-investigation.
Branch 07
Process / escalation failure
L2 acceptance delay, no OLA.

Every breach report should name its branch before anyone concludes the SOC “failed.”
